# Azure Hybrid Homelab

## Overview
This repository documents my hands-on Azure lab build as part of a larger hybrid homelab project. The goal is to build practical experience with cloud infrastructure, networking, and security by extending my home lab into Microsoft Azure.

## Current Status
Phase 1 is complete:
- Created an Azure virtual network
- Deployed a Windows Server VM
- Connected through RDP
- Began planning for site-to-site VPN connectivity

## Azure Resources Built
- Virtual Network
- Subnet
- Windows Server Virtual Machine
- Public IP for initial administration
- Network access rule for RDP management

## Configuration Summary
- Region: East US 2
- VM size: 2 vCPU / 4 GB RAM
- Azure VNet: 10.0.0.0/16
- Server subnet: 10.0.1.0/24
