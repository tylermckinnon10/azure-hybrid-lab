# Phase 1 - Azure Foundation

## Objective
Deploy a Windows Server virtual machine in Microsoft Azure to begin building a hybrid cloud homelab.

## What I Built
- Azure virtual network
- Server subnet
- Windows Server VM
- Initial remote access through RDP

## What I Learned
- Azure VM size availability can vary by subscription and region
- Cloud deployments require careful attention to networking details
- A working VM in Azure is a strong first milestone for cloud learning

## Next Phase
The next step is to build a site-to-site VPN between Azure and the home lab.
